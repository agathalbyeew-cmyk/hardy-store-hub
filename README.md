# Hardy Store Hub

## Conheça mais!

Fanix é um híbrido humano-lobo que representa o equilíbrio perfeito entre instinto afiado e estratégia precisa. Nascido da fusão entre LuxxIA e Wolf, ele carrega em sua essência criatividade e expertise.

Como fundador e responsável pela Hardy Store, Fanix atua como curador de experiências premium dentro do universo de Murder Mystery 2. Com profundo conhecimento do mercado e visão estratégica, ele constrói uma loja que vai muito além de simples transações.

Sua abordagem combina carisma natural com profissionalismo sólido, transmitindo segurança para quem compra e liberdade para quem deseja vender ou expor seus produtos.

Mascote da loja, suas maneiras de tentar atrair, porém confusas, são o que deixa essa lojinha mais amável! ❤

## 🚀 Como executar

### Pré-requisitos
- **Node.js** v16+ ou **Bun** instalado

### 1️⃣ Instale as dependências
```bash
npm install
# ou com Bun
bun install
```

### 2️⃣ Inicie o servidor de desenvolvimento
```bash
npm run dev
# ou com Bun
bun run dev
```

O site abrirá em **http://localhost:5173**

## 🛠️ Tecnologias utilizadas

- **React 18** - Biblioteca UI
- **Vite** - Build tool
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização
- **Shadcn UI** - Componentes UI
- **React Router** - Navegação
- **React Hook Form** - Gerenciamento de formulários
- **Zod** - Validação de dados
- **Capacitor** - Apps mobile
